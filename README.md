# scoop-bucket

[Scoop](https://scoop.sh) bucket for [dlm](https://github.com/sabadia/dlm-server), a cross-platform download manager.

```powershell
scoop bucket add sabadia https://github.com/sabadia/scoop-bucket
scoop install dlm
```

The manifest `dlm.json` is written by the dlm-server release workflow; do not edit it by hand.
